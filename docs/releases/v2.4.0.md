# MobiXournal v2.4.0 (Android) & Desktop v1.4.1 (Windows 11)

Released 2026-11-22 · Command Sheet, redesigned Settings & About, crisp role-based glass motion, and shared fixes across both shells.

## Command Sheet, Export & Share (Android)

- **Adaptive Command Sheet**: redesigned the overflow menu as a compact glass sheet (bottom-anchored on phones, popover below `☰` on tablets) with live document card, **Document** / **Pen & View** tabs, and inline **Export**, **Share**, and **Save As** subviews.
- **Android Share Sheet**: share notebooks directly as PDF, PNG, SVG, or Portable `.mobix` (`.pmobix`).
- **Smooth drill-down transitions**: fixed the height/view bounce when opening Share, Save As, or Export inside the Command Sheet, and used the shared menu surface for PDF bookmark actions.

## Settings, About & Updates (Both shells)

- **Unified Settings hierarchy**: consolidated Settings into seven adaptive destinations on mobile/tablet with underline tabs, full-width cards, dynamic previews, and aligned Desktop areas, section order, and Figures lists.
- **About & Feedback**: About is now its own settings area with an integrated identity page, GitHub issue doors, Credits & License, inline update checks, and remembered skipped builds on Desktop too.
- **Complete settings backup**: `autoSave` and `ringSlots` are now included in JSON settings export/import (guarded by `SettingsBackupGuardTest`).
- **Refined select popups & spacing**: anchored Settings select popups under their chevron with consistent spacing and surface tokens.

## Motion & Polish (Both shells)

- **Role-based crisp glass motion**: replaced the under-damped splash bounce (`0.82 → 1.0`, `ζ = 0.6`) with near-critically damped, role-specific motion (`POPOVER`, `SHEET` gliding up from the bottom on compact phones, and `DIALOG` scaling cleanly in place).
- **Animated inspectors & scrims**: added smooth opening/closing transitions for `InspectorLane` (plot, table, text), dialog scrims, tool strips, and compact Plot dialog sizing.
- **UI refinements**: hover highlight on quick color swatches, scaled radial HUD ring stroke, single-row `PageSelectionBar` on Desktop, and tuned glass panel alphas (`0.93` popups / `0.90` dialogs).

## Fixes

- **Audio seek on Desktop**: tapping an audio-linked stroke seeks to that stroke's timestamp instead of restarting at `0:00`.
- **Incremental `.mobix` audio**: rebuilds pages with newly available unbundled audio on incremental save.
- **PDF append on Android**: brings the pages properly when appending a PDF to an existing PDF document.
- **Focus mode & naming**: fixed Focus mode and renamed Pen side button / Ring labels.
