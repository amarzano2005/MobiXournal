# MobiXournal v1.3.0

Major update delivering powerful STEM and technical drawing tools, reliable drawing guides with dedicated glyphs, comprehensive PDF outline navigation, hold-to-snap gesture recognition, and multi-touch shortcuts.

## 📐 Drawing Guides & Gesture Snapping

- **Reliable drawing guide activation & state sync**: Fixed settings synchronization race and selection bypass so guides activate reliably on tap without getting reverted or ignored.
- **Categorized guide menu with dedicated glyphs**: Reorganized the drawing guide submenu into clean, distinct sections (**Off**, **Instruments** [Setsquare, Compass, Protractor], and **Lattices** [Page ruling, Chemistry]) with custom-crafted outline vector icons and descriptive subtitles.
- **Dynamic toolbar indicator**: The toolbar button icon dynamically reflects whichever guide is currently active on canvas.
- **Quick-toggle behavior**: Tapping an active guide immediately toggles it off.
- **Hold-to-snap auto-straightening**: Holding the stylus tip steady for ~500ms automatically straightens hand-drawn strokes into perfect lines, arcs, or regular polygons before lift-off.
- **Isometric ruling snap**: Ink snaps cleanly to the ±30° triangular lattice on isometric and isodotted stationery.

## 🧪 STEM & Technical Diagramming Suite

- **Chemistry molecular structures tool**: Dedicated chemistry drawing guide supporting 60°/120° bond angles, single/double/triple bonds, and aromatic benzene rings.
- **2D mathematical function graph plotter**: Input analytic functions and plot curves directly onto the page at customizable scales.
- **Circuit & logic gates expansion**: Expanded library of electrical switches, DC polarity markings, and digital logic components.
- **Dimensioning measurement arrows**: Double-ended engineering dimension arrows with integrated length annotations.

## 📑 PDF Navigation, Export & Round-Trip

- **PDF Table of Contents (Outline) navigation**: Jump directly across document sections using the interactive PDF bookmark hierarchy in annotated documents.
- **Vector PDF page rendering**: Optional high-fidelity vector PDF background rendering via PDFBox.
- **Editable PDF round-trip**: Capability to embed and restore full editable notebook data within exported PDF documents.
- **Page image export**: One-tap export of the active page directly as high-resolution PNG or scalable SVG vector graphics.

## 📄 Page Templates & Stationery

- **Technical stationery templates**: Added 60° isometric grid, Cornell notes layout with cue column and summary area, and millimeter graph paper presets.
- **Customizable grid & line pitch**: Configure exact ruling intervals (in mm/pt) and margins for solid ruled and graph papers.
- **Color-coded page bookmarks**: Mark key notebook pages with custom labels and colors for fast lookup.

## ✋ Gestures & Canvas Ergonomics

- **Multi-touch Undo/Redo**: Two-finger tap instantly triggers Undo; three-finger tap triggers Redo.
- **Selection alignment & distribution**: Align (left, center, right, top, middle, bottom) and evenly distribute multi-element selections.
- **Standalone active tool indicator**: Dedicated floating indicator pill positioned cleanly alongside the tab strip and toolbars.
