# MobiXournal v2.3.0 (Android) & Desktop v1.3.0 (Windows 11)

Released 2026-11-18 · 162 commits since 2.2.0 · 52 features, 52 fixes.

A PDF's chapter list stops being something the file gave you and becomes the notebook's own: you edit it, it
survives save and page operations, and it comes back out in an export. Text on a PDF behaves like text
anywhere else, and the slots you draw with recognise what they drew.

## Contents

- A PDF's chapter list is stored in the notebook: kept through save, reopen, page insertion and removal,
  merge, carried through `.xopp`, and written back into an exported PDF.
- Add, rename and delete a row with undo on either shell. An import writes a row named after the file,
  opening its first page, with the PDF's own chapters under it.
- Rows drag with their whole subtree and no destination changes; search filters the tree, a closed branch
  stays closed, and the row for the page in view is marked as you turn pages.
- The window's Contents takes the sidebar's full height beside the page thumbnails, and a title stays
  readable eight levels deep.

## PDF text

- Select with the tool already in hand: a held finger on the tablet, a double click in the window. No
  separate mode, and the ink tool stays active around the selection.
- The selection is one band per line with a draggable dot on each end, and its bar floats clear of the
  passage — above it when the pane runs out below.
- Copy, Highlight and Underline; the highlight is the band a magnetic drag snaps to, the underline one pen
  stroke per line, and both are ordinary ink in the file.
- A press has to land on a word, within a fingertip, so a press beside the text no longer selects a
  sentence across the page.

## PDF import and export

- Import shows the file's pages as a numbered grid: tap them and the Pages field fills itself, type
  `2,4-6,9` and the same previews light up. Nonconsecutive pages arrive in one action.
- Export PDF asks which pages — all, this page, or a typed run — and stops asking when the document has
  only one.
- A joined PDF keeps its bytes: the tablet pins the files a notebook names, and every join in the window
  gets its own scratch file, so two tabs on one PDF no longer overwrite each other.
- A run the base-14 faces cannot carry is typeset in the bundled DejaVu face in both shells, and an export
  whose PDF background is missing refuses instead of writing a file that lost those pages.

## The slots that drew it

- A figure, table, circuit, plot and formula slot now picks the object it just placed instead of stacking a
  second one on it — on both shells — and the slot stays in hand.
- The tablet gains a real Plot slot: the Plot button places a graph from the dialog's answers, keeps the
  slot, and picks that plot on the next press.
- A press with a slot on empty paper lets go of the selection and writes nothing, and the selection survives
  the pane's per-touch tool push.

## Pins and parts

- A press on a pin makes the join: the selected element travels onto it in one undoable step, stays
  selected, and the part behind the pin is not picked. An armed tool paints the pins its object could join
  before you start drawing.
- Pins are red in both shells and drawn as a different mark from a handle; a wire reaches an arrow's tip.
- A circuit part resizes from all eight handles on both of its dimensions, about its anchor and on its own
  axes, and a logic gate resizes like a part.

## Navigation

- Page list and bookmarks are one divided capsule in the tablet's top bar, and the lane slides open and
  closed with the page recentring behind it.
- The open view is blue in both places, nothing lights up under a press, and Manage pages moved from the
  Pages menu into the lane.
- Multi-selection is back, and the dot marks the page the commands act on — the page in view when nothing
  is picked.

## The window

- Hover, press, picked and keyboard focus read as ink and an underline everywhere, never as a filled block.
- The dial clears Windows' built-in tools and offers MobiXournal's own, so a Radial controller answers.
- Auto save keeps asking until the document lands, a save leaves the window usable, and the Save control
  turns while it writes — on both shells.

## Also fixed

- A stored split is offered only while the left pane still shows its half, and the recents card no longer
  hides the notebooks that are not on it.
- The canvas takes the size Compose has placed instead of a stale one, which is the black strip at the edge
  and the page fitted to the wrong width.
