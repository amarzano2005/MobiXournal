# MobiXournal v1.2.0

Second major release: 18 key enhancements across UI ergonomics, stylus workflow, selection operations, and settings navigation. Everything is additive and backwards-compatible — `.xopp` documents and settings backups continue to round-trip smoothly.

## 🎨 Modern Interface & Layout Refinements

- **Permanent Secondary Toolbar**: The secondary geometric figure toolbar in the top bar is now a permanent floating dock (the retired "dual toolbar" toggle has been removed). You can still configure, reorder, or hide any individual tools.
- **Classic UI retired**: Dropped the legacy classic interface toggle, committing fully to the clean floating Material 3 dock across tablets and foldables.
- **Unified chrome materials**: Coordinated the tonal palette across the app (`surfaceContainer` / implement material for toolbars, canvas surround and system bars) so controls and canvas read as a cohesive drafting surface.
- **Docked Main Toolbar restricted to left or right**: Dedicated vertical rails ensure stylus palm ergonomics (with handedness onboarding on first launch) without ever competing for the top bar edge.
- **Top Bar Quick Export PDF**: Added a quick-access Export PDF button right next to the Save button.
- **Integrated Color & Size Rail Slot**: Merged favourite swatches and full stroke settings into a single rail slot with 3 quick-tap dots, clean transparent container matching tool buttons, and popup trigger for tip sizes and styles.

## ⚙️ Overhauled Settings Experience

- **Two-level tablet layout & live search**: Redesigned settings into four macro-areas (**Input**, **Drawing**, **Interface**, **App & data**) with a permanent scannable sidebar on tablets, a pill-shaped search bar, and instant keyword search.
- **Material 3 grouped cards**: Every settings page is structured with rounded container cards, full-row touchable toggles, and clear section dividers.
- **3-subpage Shortcuts menu**: Organized keyboard shortcuts into three dedicated submenus (**Toggles**, **Tool shortcuts**, **Colour shortcuts**).
- **Clean version & about info**: Simplified the About card to display build and release versioning synced directly with the release metadata.

## ✂️ Selection & Editing Tools

- **Floating Selection Action Bar**: The selection action bar (cut, copy, duplicate, recolor, width, delete) now floats directly alongside the active ink selection on canvas instead of staying fixed at the screen edge.
- **Ink-accurate selection & non-uniform resizing**: Selection bounds accurately hug the ink contours with independent horizontal/vertical corner and edge handle resizing.
- **Desktop-accurate Vertical Space tool**: Fully matched desktop Xournal++ behavior — moving everything between the grab line and the bottom of the page with smooth boundary-crossing drag.

## 💾 Reliability & Polish

- **Instant save progress feedback**: Save progress overlay triggers immediately on tap with immutable document snapshotting on the UI thread.
- **First-run handedness onboarding**: Added explicit right- or left-handed setup in the initial startup dialog to dock the Main Toolbar correctly from day one.
- **Automated release workflow**: Integrated release automation via `scripts/todo/todo.py release` to ensure consistent changelogs and Gradle versioning.
