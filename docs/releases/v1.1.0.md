First feature release after 1.0.0: 48 commits with new tools, a new modern interface and
on-device handwriting search. Everything is additive — `.xopp` files stay fully compatible
with v1.0.0, and settings backups stay at version 1, so even old ones still import.

## 🎨 Modern interface (now the default)

- **Modern UI**: floating Main Toolbar and an adaptive Secondary Toolbar dock — rounded
  Material 3 surfaces with tonal elevation, squircle buttons, pill tabs, frosted badges and
  a grouped undo/redo cluster.
- The **Secondary Toolbar dock encloses only the active figures** and widens or shrinks with
  their number; the **top bar floats** in the same style.
- Switch back to the **Classic UI** from **Settings → Appearance → Modern interface**.
- **Naming disambiguated** everywhere (settings, docs, components): the figure rail is the
  *Secondary Toolbar*, the primary rail the *Main Toolbar*.
- **Top bar**: one-tap **Save** next to undo/redo, **Split View** moved next to search, the
  tab-overview button removed.
- **Row-based pickers** for tool groups and for the triangle/trapezoid variant menus (two per
  row, wider for the big groups), with the pencil that opens the variant's angle dialog.
- **Compact overflow menu** with 1-tap pen-preset chips.

## 🔬 STEM tools

- **Active circuits group** (new): diodes, LEDs, zener diodes, op-amps, BJT NPN/PNP, DC
  voltage sources and current sources, drawn as single-stroke schematic glyphs and aligned
  with the reference schematics (op-amp `+`/`−` signs clear of the pins, clean shaded anode
  edge). The previous circuit group is now named **Passive circuits**.
- **Trapezoid tool** with three variants: **isosceles** (default), **right-angled** and
  **scalene**, with its two base angles editable and live preview — the figure always fits the
  drag and the angles are what is kept exactly.
- **Triangle submenu** with four kinds: **equilateral** (default), **right-angled**,
  **isosceles** and **scalene** (three editable angles, sum 180°, live preview).
- Tool ordering tidied up: **line and rectangle** toggles in the figures settings, square
  placed after the rectangle with an outline glyph, generic shape moved before the Cartesian
  axes, star removed from the STEM figures.

## ✍️ Pen & stylus

- **Pressure controls that actually bite**: the sliders now use desktop Xournal++'s own
  ranges (**minimum pressure 0.01–1.00**, **multiplier 0.5–4.00×**) and feed a single width
  expression, so moving them changes the drawn stroke instead of doing nothing. With
  *Pressure sensitivity* off, both are shown **disabled with the reason**.
- **Pen diagnostics** prints the raw pressure per event plus the `sens/mult/min/base → width`
  line the filter produced.
- **Pen parameter presets** with editable names, reorder arrows and factory defaults for new
  presets; edits apply to the *active* preset and selection is tracked by id (no more multiple
  presets highlighting at once).
- **Palette matched to desktop Xournal++**: black, red, green, blue, orange, yellow, magenta,
  white.

## 🔎 Search & handwriting recognition

- **Search the ink**, not just text boxes and PDF text: **Google ML Kit Digital Ink
  Recognition** on device (300+ languages, print and cursive) with an **offline pure-Kotlin
  fallback**.
- **Fuzzy, multi-candidate matching**: candidate hypotheses, accent/diacritic normalization,
  continuous multi-word phrases and Levenshtein tolerance.
- **Modern Material 3 search pill** with the `1/3` match badge, auto-focus, keyboard Search
  action, quick clear, an AI **indexing dialog** when search opens and instant results while
  typing; the search UI is in English.
- **Performance**: indexing is non-blocking, so writing, selecting and scrolling no longer
  freeze on heavy documents; search re-indexes across tab switches and the hamburger menu is
  positioned correctly; candidate bounding was tightened to cut false positives.

## 🛠️ Editing, canvas & data safety

- **Selection marquee edge auto-scroll** is anchored to the page, so dragging the band to the
  screen edge scrolls and extends the selection exactly like desktop Xournal++.
- **Tab snapshots are written atomically**, and a snapshot that exists but cannot be parsed is
  left untouched (and reported) instead of being overwritten by a blank page — no more blank
  page when reopening a tab.
- The **table row counter counts data rows only** (the header no longer eats the first row),
  and the figures' **stroke width** now syncs live and persists.

## ⚙️ Settings

- **Backup import is validated**: a file that is not a MobiXournal backup, or one written by a
  **newer app version**, is refused with a clear message instead of being accepted silently.
  Older backups (v1, even partial ones) still import.
