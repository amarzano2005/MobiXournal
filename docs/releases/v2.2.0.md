# MobiXournal v2.2.0 (Android) & Desktop v1.2.0 (Windows 11)

2026-11-13 · 165 commits since 2.1.0 · 52 features, 46 fixes.

## Saving

- The notebook saves itself once the strokes go quiet, on both shells.
- A dot on the strip lights at the first stroke and goes out when the save lands; the save itself is a
  word in the corner on the tablet and nothing over the page in the window.
- Save is greyed when the file already holds the page. A never-saved document asks where to put it first.
- Writes run on their own lane: drawing and ink keep working while bytes go out, and the page stays on
  screen instead of becoming a placeholder.
- A document is written, checked, then replaced. An interrupted save cannot leave a truncated notebook.

## Selection

- A line or arrow has one handle per end, on its own shaft. The box is gone; the grips set length and
  aim, and turning happens about the ink with the ring on it.
- A figure's corner changes its proportions on the tablet too, and a corner dragged on a recognised shape
  follows the pointer instead of snapping to hidden rails.
- A selected element shows its own pins and the ends it can join.

## Pins and the magnet

- Every figure carries pins, at its corners and side midpoints. Ink does not.
- The magnet works during insertion: a rectangle let go eight points short of a line's end is written with
  its corner on it. Dragging a figure onto an end does the same.
- A wire's end is a square, a pin a filled dot, edged so they read over a ruled page.
- After an insert the page goes back to selection, so the figure can be moved onto a pin at once.
- Settings → Figures is one question, *Snap when*: lift or held tip, not both.

## Export

- Export As collects PNG, SVG and portable `.pmobix` in one card. Save As asks the same way: the format
  in the card, the file name in the picker, the app's own format first.
- A portable copy carries the pictures, PDFs and recordings the notebook only names, and lists the ones it
  could not embed.
- Opening a file reports which parts are inside it and which are missing.
- An opened portable copy is never saved in place: Save becomes Save As on a working `.mobix`.

## Plots

- The analysis report sits on either side of the frame, obeys its Summary switch, and its chips wrap
  instead of being clipped.
- Each critical point has its own glyph and the plot a legend; a local minimum is not marked in the
  curve's blue.

## Files

- A file declares what it requires; a build that cannot honour it writes, refuses or warns, on both shells.
- Unknown types and fields survive edits, merges, copy, paste and undo.
- Reads are bounded: entry count and size caps, verified digests, entry names that cannot escape the
  archive, one error type instead of a raw crash.
- The `.mobix` v1 format is published for outside implementers, with JSON Schemas, a conformance checklist
  and an independent reader (`tools/mobix-cli`: inspect, list, validate, extract, export-json, new,
  retitle).

## Also fixed

- The PDF export glyph is dimmed on a read-only tab.
- A file's real name stays in its field, which no longer wraps into the canvas.
- The crash snapshot's save runs on the save lane, not the UI thread.
